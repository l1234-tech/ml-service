### **1. Сырчин Андрей — Backend Developer \+ CI/CD**

**Выполненные задачи:**

* **Разработка API на FastAPI**

  * Реализованы три обязательных эндпоинта:

    * `POST /upload-model` – загрузка сериализованной модели в формате `.pkl`

    * `POST /predict` – получение предсказаний для одной или нескольких записей

    * `POST /predict-from-csv` – загрузка CSV-файла (сырого или предобработанного) с возвратом ROC-AUC и предсказаний

  * Добавлена **валидация входных данных**

* **Интеграция ML-модели**

  * Организована подгрузка предобученной модели и пайплайна предобработки

  * Обработка ошибок (модель не загружена, неверный формат данных, отсутствие целевой переменной)

* **Логирование сервиса**

  * Реализовано логирование основных событий (старт сервера, загрузка модели, каждый запрос к `/predict`, ошибки)

  * Логи выводятся в консоль

* **CI/CD (Sourcecraft)**

  * Настроен CI-сценарий с автоматическим тестированием:

    * Линтинг бэкенда (`flake8`, `black`)

    * Проверка импортов и базовых модульных тестов (pytest)

    * Линтинг фронтенда (если применимо)

    * Выполнение обучения модели и формирование артефактов (файл с пайплайном и др файлами) 

    * Артефакты содержат в себе все модели, картинку roc_auc, датасеты (на 50 человек) для быстрой проверки

  * Автоматическая проверка при каждом push/merge

### **2. Мастеров Артем — ML Engineer \+ Frontend Developer**

**Выполненные задачи (ML-часть):**

* **Предобработка данных**

  * Очистка пропусков и выбросов

  * Кодирование категориальных признаков (One-Hot Encoding / Label Encoding)

  * Масштабирование числовых признаков (StandardScaler)

  * Разделение на train/test 

* **Feature engineering и отбор признаков**

  * Анализ корреляции (выполнено только локально)

  * Отбор значимых признаков (на основе взаимной информации / важности из Random Forest)

* **Обучение и сравнение моделей**

  * Реализованы 3 алгоритма: **логистическая регрессия**, **случайный лес**, **градиентный бустинг (LightGBM/XGBoost)**

  * Оценка качества по метрике **ROC-AUC** (на кросс-валидации и тестовой выборке)

  * Выбрана лучшая модель (и загружена на сайт) 

* **Визуализация метрик**

  * Реализован вывод ROC-кривой и значения AUC (как на бэкенде, так и через фронтенд)

  * График доступен после выполнения `/predict-from-csv`, если передан `loan_status`

* **Сериализация модели**

  * Сохранение лучшей модели \+ пайплайна предобработки в `.pkl`

**Выполненные задачи (Frontend):**

* **Разработка пользовательского интерфейса (HTML/JS)**

  * Минималистичный, но полностью функциональный интерфейс

  * Форма для ручного ввода признаков клиента → вызов `/predict`

  * Форма для загрузки CSV-файла → вызов `/predict-from-csv`

  * Отображение предсказаний и метрики ROC-AUC (если доступна)

  * Интеграция с API (fetch-запросы, обработка ответов и ошибок)

## Сборка проекта (через uv):

```bash
- cd backend

- uv sync
```

---

## Запуск приложения:

```bash
- cd backend

# запуск обучения модели  и созадние артефактов (модели, картинки roc_auc, файлы csv для оценки моделью)
- uv run python ml/train.py

# запуск самого приложения
- uv run uvicorn main:app --reload    
```
